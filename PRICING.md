# Pricing & Cost Structure — AI Mockup Generator

## 1. Pricing Model

AI Mockup Generator operates on a subscription basis. End users pay a fixed recurring fee (monthly and/or annual), not a per-generation charge. This model is intended to keep spend predictable for teams that generate mockups regularly and want stable budgeting rather than variable usage bills.

## 2. Subscription Tiers

| Tier     | Monthly Price |   Generations / Month | Max Images / Generation | Additional Features                                                | Support                |
| -------- | ------------: | --------------------: | ----------------------: | ------------------------------------------------------------------ | ---------------------- |
| Starter  |    ₹499/month |  30 generations/month |                       3 | Core generation, 2 aspect ratios, download access                  | Email support          |
| Pro      |  ₹1,299/month | 100 generations/month |                       3 | Everything in Starter + custom prompt support, priority processing | Priority email support |
| Business |  ₹2,999/month | 300 generations/month |                       3 | Everything in Pro + team seats, enterprise support, custom DPA     | Dedicated support      |

Implementation-backed note: backend generationCount is clamped to 1-3 per request, so a single request can return up to 3 generated images.

## 3. Gemini API Cost Breakdown (Internal / Transparency Section)

- Model used in the current implementation: gemini-2.5-flash-image (override supported via GEMINI_MODEL).
- Request composition per generation call:
  - 1 text prompt generated by the platform prompt builder (long, multi-section instruction block with brand/product/industry/aspect-ratio variables).
  - 1 uploaded product image sent as inline base64 image data.
- Google billing basis (provider-side):
  - Text input tokens: ₹27.80 per 1M input tokens ($0.30/1M)
  - Image input tokens/tiles: ₹27.80 per 1M input tokens ($0.30/1M)
  - Image output generation: ₹2,779 per 1M output tokens ($30/1M)

Prompt-size estimate reference:

- Estimated text tokens per request from current prompt template + user fields (estimated working estimate): ~590 tokens
- Estimated total input tokens sent per image-generation request (text + image, estimated working estimate): ~1,190 tokens
- Estimated-case split used for the estimate: ~590 text input tokens + ~600 image input tokens

Estimated platform-side API cost:

- Single-generation request (1 image output): ~₹3.70 per image (~$0.039)
- Request producing 3 outputs: ~₹11.02 per request (~$0.119)

These are internal infrastructure costs used to support subscription pricing and are not charged to users as separate per-generation line items.

## 4. Free Trial

- Free trial available: Yes
- Duration: 7 days
- Generations allowed during trial: 5 generations
- Credit card required: No

## 5. Billing & Payment

- Billing cycle: Monthly and annual
- Annual discount: 20%
- Payment methods accepted: UPI, Credit/Debit Card, Net Banking (subject to payment processor integration)
- Invoicing: Yes — GST-compliant invoices are provided for all transactions as required under Indian tax law

## 6. Overage Policy

When a user reaches their monthly generation allowance, behavior depends on the account policy configured by the platform operator.

- Overage policy: Hard stop — generations are blocked when the monthly limit is reached. Users are prompted to upgrade their plan.

## 7. Refund Policy

- No refunds are provided once a billing cycle has started. Users may cancel at any time; access continues until the end of the current billing period.
